# Concrete CoverUtil observer class

The host bridge at libGbl.so 0x973b94 supplies the missing ABI evidence. Its RTTI identifies bl::MapBusinessDataObserver as a dice::IMapBusinessDataObserver subclass. Slot 2 loads its owner's bl observer from owner+0x28c, then tail-dispatches that observer's slot 2 without changing r1/r2/r3. The known dice callback shape is bool(int, const void*, void*). This supports the same binary call shape for bl::IBLMapBusinessDataObserver; callback spelling/const qualifiers are inferred from the forwarded interface, not independently exported bl method names. A null observer returns 1.

Added bl::IBLMapBusinessDataObserver with destructor slots 0/1 and business callback slot 2. Concrete NS_MultiScreenBase::CoverUtil inherits MapSurfaceViewObserver at +0 and the business observer at +4. ARM32 compiler checks verify size 0xa8 and 14 known field offsets. Original constructor values and nested String16/SurfaceConfig construction are represented, with unknown fields explicitly named rather than assigned invented meaning.

The compiler emits the original 44-byte vtable-group layout: primary map callback/destructor pair/business callback, secondary destructor pair/business callback with -4 thunks. See v21_verified/cover_rebuilt_vtable.json and compare cover_observer_vtables.txt. Primary/secondary destructor slots and field offsets were checked independently of symbol-name similarity.

The map callback now consumes the verified surface/event gates and resets counter. Business callback handles event 0x17 through flag updates, supported-buffer averaging and RGB config writes; other events return true unchanged. Original flag bytes are published before invoking external configuration services. No stale local flags are copied back after those calls, preserving possible synchronous mutations. The first-render predicate uses verified signed comparison logic.

Validation: native ASan/UBSan tests instantiate the actual rebuilt class, verify constructor defaults and adjusted observer pointers, dispatch map/business callbacks through both base interfaces, and check resulting counter, flags and RGB config calls. Complete class and all 32 production translation units pass ARM Linux musl compile-only checking. ARM object vtable extent/slots and 14 field offsets pass checks. Existing original Thumb differential evidence validates the extracted arithmetic/state decisions; this is not Android runtime validation of the new class.

Still incomplete: setConfig and real graphics/capture services, top-render callback binding, logging, Packet's host package construction, and complete module registration. The class is compiled but NOT installed into Packet or enabled in a factory.
