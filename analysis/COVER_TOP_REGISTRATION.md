# Cover top-render registration and setConfig entry

The optional initialization branch now registers a real plain canvas callback with CGWorkStation::setTopRenderCallback. It saves the target before calling the host setter, so immediate synchronous dispatch can reach the fully initialized CoverUtil. Re-registering another CoverUtil replaces the target while preserving the same dispatcher entrypoint. The dispatcher invokes the real reconstructed TopRenderCoverCallback and handles empty callback storage.

Original 0x18a08 is a module-local dispatcher over private closure storage at 0x6f00c; that range has no dynamic exports. Host registration passes only void(*)(CGCanvas*). Rebuilt storage uses a private std::function capturing the raw CoverUtil pointer. No std::function object, fabricated GPI::Closure object, or assumed 20-byte closure layout crosses a host ABI boundary. This is a source-level implementation choice for private state, not a claim that original GPI closure allocation/refcount representation has been reproduced. The captured target is non-owning as in the original raw member binding; host callback use must end before target destruction.

initializeConfiguredCover now installs the optional callback after map-observer registration when flag +0x14 is set, and reports TopRenderRegistered only after calling the host setter. Added the original void setConfig(CGContext*, IMapDevice*, IMapView*, SurfaceConfig) entrypoint over the same implementation. Its public by-value argument is copied once; internal reference helpers avoid adding an extra by-value copy. The staged API retains explicit failure/registration outcomes.

Native ASan/UBSan tests cover exact canvas forwarding to real draw/capture code, replacing callback targets, stable dispatcher pointer, synchronous dispatch during registration, optional pipeline installation and the real setConfig entrypoint. A String16/CGString boundary copy test confirms one by-value SurfaceConfig copy. All 37 production source files compile for ARM Linux musl; this does not establish Android library/runtime compatibility or a strict link.

Original logging is not reconstructed. Existing staged guards for unexpected missing images remain documented behavior outside the normal original path. Packet's host package base, module factory construction, remaining lifecycle behavior and Android strict linking/device validation remain incomplete. No usable replacement SO.
