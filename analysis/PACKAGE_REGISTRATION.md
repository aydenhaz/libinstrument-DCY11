# Package registration component (2026-10-21)

Original init 0x14e40 constructs UTF-16 CGString "CGIPLPacket" and "com.autonavi.package.GIPLPacket", then calls the host ClassNode_CGPackage constructor with node at 0x6fd28 and Thumb factory pointer 0x2eb09. Temporary alias and name strings are destroyed in that order, then the host node destructor is registered with __cxa_atexit and DSO 0x68be8. These are not the package resource name "InstrumentPannelLargePackage".

Host constructor 0x1b3e58 owns CGString at node+0, stores the factory at +0x18 and list-next at +0x1c, and inserts the node into its host-managed structures. Host destructor 0x1b3efc unlinks the node then destroys the string. The ARM32 node layout is 0x20 bytes with no vptr; constructor/destructor remain imported host methods. ClassNode_CGPackage header now represents this layout and forbids copying registration nodes.

The new createPackageRegistration helper accepts a real factory and returns a unique_ptr owning the host registration node. It uses identical class/alias strings and preserves temporary-string destruction order. It rejects a null factory as an explicit helper precondition. The private unique_ptr never crosses the host ABI. It uses heap ownership rather than claiming to reproduce the original static node address/atexit mechanism. The caller must retain the node for the entire desired registration lifetime.

This helper is NOT automatically invoked: rebuilt Packet does not yet construct CGFragmentPackage and full virtual/base state. Original factory 0x2eb08 still has no replacement suitable for host registration. Other original initializer objects (locks/global objects) also remain incomplete. Removed four legacy constructor callbacks that merely registered no-op destructors; archived them under analysis/rejected/module_init_placeholders.cpp.txt. Removing these inert callbacks does not claim any original initialization is complete.

Validation: native ASan/UBSan verifies strings, factory identity, temporary cleanup, node ownership lifetime and rejection before registration for null factory. Original Thumb trace validates literal strings, factory address, static node address, destructor registration pointer/DSO and ordering, with host services intercepted. ARM Linux musl compile-only 39/39 passes and enforces node size 0x20. No Android strict link, host registration integration, or replacement SO is available.
